# SpinSphere

A small Three.js scene I made to learn 3D on the web. It shows a lit sphere that spins on its own.

## What it does

- Sphere with a point light and orbit controls (auto rotate, no zoom or pan)
- GSAP intro animation for the sphere, nav bar and title
- Click and drag to change the colour of the sphere
- Resizes with the browser window

## Stack

Three.js, GSAP, Vite, plain JavaScript and CSS.

## Run it locally

```
cd SpinSphere
npm install
npm run dev
```
